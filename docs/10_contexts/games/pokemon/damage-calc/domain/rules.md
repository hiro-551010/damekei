# ドメインルール（damage-calc）

## レベル・個体値（固定値）

チャンピオンズではレベル・個体値はユーザーが変更できない固定値。

| 項目 | 値 |
|---|---|
| レベル | 50（固定） |
| 個体値（全ステータス） | 31（固定） |

## StatPoints（能力ポイント）

チャンピオンズにおける努力値相当の仕組み。

| ルール | 値 |
|---|---|
| 各ステータスの範囲 | 0〜32 |
| 全ステータス合計の上限 | 66 |
| 1 ポイントの効果 | 能力値 +1（性格補正なし時） |

スカウト直後のデフォルト配分：2 ステータスに 32、1 ステータスに 2（いわゆる「ぶっぱ」配分）。

## StatBoosts（ランク補正）

| ルール | 値 |
|---|---|
| 各ステータスの範囲 | −6〜＋6 |

## Pokemon

- `species` は必須。null 不可
- `item` は null 可（持ち物なし）
- `ability` は `species.abilities` に含まれる値でなければならない
- 同一インスタンスを攻撃側・防御側の両方に渡すことは禁止しない（コピーはユースケース側で行う）

## Move

- `category` が `status` のわざはダメージを与えない。計算リクエストとして受け付けるが、結果の `rolls` はすべて 0 になる
- `power` が `null` の場合（変動ダメージわざ）は `@smogon/calc` の内部処理に委譲する

## DamageResult

- `rolls` は常に 16 要素（`@smogon/calc` の仕様）
- `percentages` の値は防御側の **現在 HP** ではなく **最大 HP** に対する割合とする
- `knockoutChance` の判定基準:

| 分類 | 条件 |
|---|---|
| `guaranteed` | `rolls` の全 16 通りが防御側最大 HP 以上 |
| `high` | `rolls` の 9〜15 通りが防御側最大 HP 以上 |
| `low` | `rolls` の 1〜8 通りが防御側最大 HP 以上 |
| `guaranteed_no` | `rolls` の全 16 通りが防御側最大 HP 未満 |

## バリデーションのレイヤー責任

- **domain 層**：不変条件の検証（StatPoints 範囲・合計等）
- **presentation 層**：入力形式のバリデーション（文字列 → 数値変換、未入力チェック等）
- domain のバリデーション違反は `DomainError` を throw する（`docs/00_governance/error-policy.md` 参照）
