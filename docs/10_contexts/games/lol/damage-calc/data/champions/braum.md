# Braum（ブラウム）champion-passives.json

## champion-passives.json エントリ

なし（Meraki データをそのまま使用）。

## 各スキルの扱い

| スキル | 扱い |
|---|---|
| Q（Winter's Bite） | magic。Meraki 値をそのまま使用 |
| W（Stand Behind Me） | ダメージなし（ジャンプ・盾形成）。preMitigation = 0 で問題なし |
| E（Unbreakable） | ダメージなし（方向シールド）。preMitigation = 0 で問題なし |
| R（Glacial Fissure） | magic。Meraki 値をそのまま使用 |

## 対象外

| 項目 | 理由 |
|---|---|
| Passive（Concussive Blows） | AA / スキル 4 ヒットでスタン付与。追加ダメージなし |
