# Rakan（ラカン）champion-passives.json

## champion-passives.json エントリ

なし（Meraki データをそのまま使用）。

## 各スキルの扱い

| スキル | 扱い |
|---|---|
| Q（Gleam） | magic。Meraki 値をそのまま使用 |
| W（Grand Entrance） | magic。Meraki 値をそのまま使用 |
| E（Battle Dance） | ダメージなし（ダッシュ + シールド）。preMitigation = 0 で問題なし |
| R（The Quickness） | magic。Meraki 値をそのまま使用 |

## 対象外

| 項目 | 理由 |
|---|---|
| Passive（Fey Feathers） | シールド自動生成。ダメージ出力に影響なし |
