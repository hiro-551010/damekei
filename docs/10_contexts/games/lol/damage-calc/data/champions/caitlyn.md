| スキル | 扱い |
|---|---|
| Q（Piltover Peacemaker） | physical。Meraki 値をそのまま使用 |
| W（Yordle Snap Trap） | physical。設置トラップのダメージ値を Meraki が返す |
| E（90 Caliber Net） | physical。Meraki 値をそのまま使用 |
| R（Ace in the Hole） | physical。Meraki 値をそのまま使用 |

| 項目 | 理由 |
