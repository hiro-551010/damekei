# Janna（ジャンナ）champion-passives.json

## champion-passives.json エントリ

なし（Meraki データをそのまま使用）。

## 各スキルの扱い

| スキル | 扱い |
|---|---|
| Q（Howling Gale） | magic。Meraki 値をそのまま使用 |
| W（Zephyr） | magic。Meraki 値をそのまま使用 |
| E（Eye of the Storm） | ダメージなし（シールド付与）。preMitigation = 0 で問題なし |
| R（Monsoon） | ダメージなし（ノックバック・回復）。preMitigation = 0 で問題なし |

## 対象外

| 項目 | 理由 |
|---|---|
| Passive（Tailwind） | 移動速度ボーナスによる passive AS 増加。ダメージ出力に影響なし |
