## ダメージ計算画面（`/lol/damage-calc`）

### レイアウト概要

上段 2 カラム（攻撃側 / 防御側） ＋ 下段全幅（ダメージ結果）の構成。

```
┌──────────────────────────────────────────────────────┐
│  ヘッダー（サービス名）                               │
├────────────────────────┬─────────────────────────────┤
│  攻撃側パネル          │  防御側パネル                │
│   チャンピオン選択     │   チャンピオン選択           │
│   レベル入力           │   レベル入力                 │
│   スキル振り分け       │   ビルド（6スロット）        │
│   ビルド（6スロット）  │                             │
├────────────────────────┴─────────────────────────────┤
│  ダメージ結果（Q / W / E / R）                        │
│  ┌──────┬──────────────┬──────────┬────────────────┐ │
│  │ スキル│ ダメージ種別 │ 軽減前   │ 最終ダメージ   │ │
│  ├──────┼──────────────┼──────────┼────────────────┤ │
│  │ Q Lv3│ 魔法         │ 420      │ 280            │ │
│  │ W Lv1│ 物理         │ 130      │ 95             │ │
│  │ E Lv5│ 魔法         │ 580      │ 387            │ │
│  │ R Lv1│ 真           │ 200      │ 200            │ │
│  └──────┴──────────────┴──────────┴────────────────┘ │
└──────────────────────────────────────────────────────┘
```

### コンポーネント構成

```
LolDamageCalcPage（Client Component）
├── ChampionPanel（attacker）
│   ├── SearchableSelect<string>    # チャンピオン選択（shared/components/）
│   ├── LevelInput                  # レベル入力（1〜18）
│   ├── SkillAllocationForm         # スキル振り分け（Q/W/E/R）
│   └── BuildForm                   # アイテム 6 スロット
│       └── ItemSelect × 6
├── ChampionPanel（defender）
│   ├── SearchableSelect<string>    # チャンピオン選択
│   ├── LevelInput
│   └── BuildForm
└── DamageResultTable               # Q/W/E/R 全スキルのダメージ一覧
```

## 各コンポーネント仕様

### ChampionPanel

攻撃側・防御側で共用。`variant` prop（`"atk"` / `"def"`）でカラーテーマを切り替える。
攻撃側のみ `SkillAllocationForm` を持つ。

### LevelInput

- 1〜18 の整数をスピナーまたは直接入力で変更
- チャンピオン選択前はデフォルト 1
- レベル変更時は `SkillAllocationForm` の残りポイントを再計算する

### SkillAllocationForm

スキルポイントを Q/W/E/R に振り分けるコンポーネント。

```
Q  ●○○○○  [−] [+]   残り: 5pt
W  ○○○○○  [−] [+]
E  ○○○○○  [−] [+]
R  ○○○     [−] [+]
```

- `[+]` / `[−]` ボタンでランクを 1 ずつ増減する
- **残りポイント** = `level − (q + w + e + r)` を常に表示する
- 残りポイントが 0 のとき `[+]` は無効化
- 各スキルの最大ランクに達したとき `[+]` は無効化（Q/W/E は 5、R は 3）
- **R の制限**：チャンピオンレベルに応じた上限を超える `[+]` は無効化
  - level 1〜5 → R は習得不可（上限 0）
  - level 6〜10 → R 上限 1
  - level 11〜15 → R 上限 2
  - level 16〜18 → R 上限 3
- レベル変更でポイントの合計が超過する場合、各スキルのランクを均等に削る（高ランク順）
- チャンピオン未選択時は無効化

### BuildForm

- アイテム 6 スロット。各スロットに `ItemSelect`（`shared/components/SearchableSelect`）
- 未選択スロットは「なし」と表示
- 同一アイテムを複数スロットに選択しようとした場合はバリデーションエラーを表示

### DamageResultTable

Q / W / E / R の 4 行でダメージを一覧表示する。

| 列 | 内容 |
|---|---|
| スキル | スキット名 + 現在ランク（例: `Q Lv3`。未習得は `Q -`） |
| ダメージ種別 | 物理 / 魔法 / 真 バッジ |
| 軽減前ダメージ | `preMitigationDamage` |
| 有効防御力 | `effectiveResistance`（物理 = 有効アーマー、魔法 = 有効MR、真 = −） |
| 最終ダメージ | `postMitigationDamage`（太字で強調） |
| 軽減率 | `damageReductionPercent`（%） |
| HP削減割合 | `hpPercent`（%）= 最終ダメージ / 防御側総HP × 100 |

- 未習得スキル（rank = 0）は行をグレーアウトし、ダメージを `—` で表示
- チャンピオンまたはスキル振り分けが未設定の場合はプレースホルダー行を表示

## UX 方針

- **リアルタイム計算**：パラメータ変更のたびに自動で再計算（ボタン不要）
- **スキル振り分けと結果の連動**：ランクを変えると即座にその行のダメージが更新される
- **スワップ**：攻撃側 ⇄ 防御側 のパラメータを一括入れ替えするボタンをパネル間に配置
- **構築保存連携**（Phase 2）：ヘッダーの「保存」ボタンから `builds` コンテキストの `SaveBuild` を呼び出す。保存時に `gameId: "lol"` を付与する
