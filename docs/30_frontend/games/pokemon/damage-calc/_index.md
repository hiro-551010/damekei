## ダメージ計算画面（`/pokemon/damage-calc`）

### レイアウト概要

デスクトップ 3 カラム構成。攻撃側 ／ 中央列 ／ 防御側 を横並びで表示する。

```
┌──────────────────────────────────────────────────────┐
│  ヘッダー（サービス名）                               │
├───────────────┬──────────────┬───────────────────────┤
│  攻撃側タブ   │              │  防御側パネル          │
│  [枠1][枠2]…  │  わざ選択    │   ポケモン選択         │
│  攻撃側パネル │  フィールド  │   種族値プレビュー     │
│   ポケモン選択│  素早さ比較  │   性格 / SP            │
│   種族値プレビ│  ヒット数    │   特性 / 持ち物        │
│   性格 / SP   │  ダメージ結果│   ランク補正           │
│   特性 / 持ち物│  ⇅ スワップ │                       │
│   ランク補正  │              │                       │
└───────────────┴──────────────┴───────────────────────┘
```

### コンポーネント構成

```
DamageCalcPage（Client Component）
├── [攻撃側タブ × 6]              # ポケモン枠の切り替えタブ
├── PokemonPanel（攻撃側）
│   ├── SearchableSelect<number>  # shared/components/ から参照
│   ├── NatureSelect
│   ├── StatPointsForm
│   ├── AbilitySelect
│   ├── ItemSelect
│   └── BoostForm
├── [中央列]
│   ├── MoveSelect
│   ├── FieldConditionForm
│   ├── [素早さ比較]
│   ├── [ヒット数セレクタ]
│   ├── [ダメージ結果]
│   └── [スワップボタン]
└── PokemonPanel（防御側）
```

## 各コンポーネント仕様

### 攻撃側タブ（6 枠）

- 攻撃側ポケモン枠を 6 つ保持し、タブで切り替える
- 各枠は `PokemonState`（ポケモン・性格・SP・特性・持ち物・ランク補正）と選択中のわざを独立して記憶する
- タブにはポケモン名を表示。未登録の枠は「枠 N」と表示
- 切り替え時は現在の枠を保存し、選択した枠の設定を復元する

### SearchableSelect（shared/components/）

- インクリメンタル検索付きのカスタムドロップダウン
- キーボード操作（↑↓ / Enter / Escape）対応
- variant: `"atk"` / `"def"` / `"neutral"` でフォーカスリングの色を切り替え

### MoveSelect

- 攻撃側ポケモンが覚えられるわざのドロップダウン
- タイプバッジ・わざ名・分類（物/特/変）・威力を各行に表示
- ポケモン未選択時は無効化

### FieldConditionForm

- 天候：なし / 晴れ / 雨 / 砂嵐 / 雪
- テレイン：なし / エレキ / グラス / ミスト / サイコ
- 折りたたみ可能

### 素早さ比較（インライン）

- 攻撃側・防御側の実際の素早さ実数値を表示
- 性格補正・ランク補正・持ち物（こだわりスカーフ 1.5 倍 / くろいてっきゅう 0.5 倍）を反映
- 先攻 / 後攻 / 同速 バッジを表示

### ヒット数セレクタ・ダメージ結果（インライン）

（省略。旧設計から変更なし）

## UX 方針

- **リアルタイム計算**：パラメータ変更のたびに自動で再計算
- **タブによる枠管理**：攻撃側 6 枠を切り替えながら効率化
- **スワップ**：攻撃側 ⇄ 防御側 のパラメータを一括入れ替え
- **構築保存連携**：ヘッダーの「保存」ボタンから `builds` コンテキストの `SaveBuild` を呼び出す
  - 保存時に `gameId: "pokemon"` を付与する

## デザイントーン

- パステル系配色（攻撃側：オレンジ、防御側：エメラルド）
- 丸みのある UI（rounded-xl / rounded-2xl）
- タイプカラーはポケモン公式に準じた色使い
